## 🧲 الالتصاق الذكي (Smart Snapping)

### الحالة: بدون التصاق

```
حالة عادية:
┌────────────────────────────────────┐
│       القاعة الأولى (مرسومة)        │
│    ┌──────────────┐                │
│    │              │                │
│    │              │                │
│    └──────────────┘                │
│                                    │
│  وتحاول رسم القاعة الثانية...      │
│             ↖ (بدون مؤشرات)        │
│                                    │
└────────────────────────────────────┘

النقرة عادية جداً
التصاق: ❌ لا
```

### الحالة: التصاق ذكي

```
التصاق ذكي:
┌────────────────────────────────────┐
│       القاعة الأولى (مرسومة)        │
│    ┌──────────────┐                │
│    │              │                │
│    │           🔵 ← دائرة زرقاء      │
│    └──┻───────────┘                │
│       ↑ خط أزرق متقطع               │
│       (من الفأرة)                   │
│                                    │
│  اقتربت من الزاوية!                │
│             ↖ (مع مؤشرات!)         │
│                                    │
└────────────────────────────────────┘

الأسفل: 🧲 التصاق بالزاوية القديمة
النقرة: ✅ التصاق تلقائي!
```

### العلامات البصرية للالتصاق

```
الخط الأزرق:
───ᴬ───ᴮ───ᴬ───┊ خط متقطع من النقطة الحالية
        ^      └─ يشير للزاوية القديمة
    (موجودة)

الدائرة الزرقاء:
     ⊙  ← دائرة ملونة بلون أزرق فاتح
   الزاوية المقترحة

الرسالة:
🧲 التصاق بالزاوية القديمة
↑
تظهر أسفل الشاشة
```
