# لعبة المافيا - نسخة المؤتمر المرئية

تم تحديث لعبة المافيا إلى واجهة مؤتمر رسومية احترافية مع تأثيرات بصرية عالية الجودة.

## ملخص التحديثات

### ✅ تم إنجازه:
1. **حذف النسخة الفردية** - تم حذف `index.html` و `game.js` و `style.css` من المجلد الرئيسي
2. **تصميم جديد كامل** - واجهة مؤتمر رسومية مع:
   - لوحة أفقية لعيراض الشخصيات (Conference Table)
   - تأثيرات انيميشن متقدمة (float, pulse, glow, eyeClose/Open)
   - نظام مؤقت متطور
   - عرض حي لحالة اللاعبين

3. **تأثير إغلاق العيون** - تأثير واقعي يشبه إغلاق العيون من الأعلى والأسفل
4. **دوال جديدة** - `triggerEyeClose()`, `startTimer()`, `renderConferenceBoard()`

## إضافة الصور والأصوات

### مجلد الصور (`public/images/`)
ضع صور الشخصيات الكرتونية هنا:
- الأبعاد المقترحة: 200x240px أو مربعة 240x240px
- الأنواع المدعومة: PNG, SVG, JPG

**أمثلة الملفات:**
- `player-1.png` - صورة اللاعب الأول
- `player-2.png` - صورة اللاعب الثاني
- (إلخ...)

### مجلد الأصوات (`public/sounds/`)
ضع الأصوات الأساسية هنا:
- `click.mp3` - صوت نقر الزر
- `whisper.mp3` - همسات المافيا
- `death.mp3` - صوت الموت
- `timer.mp3` - إنذار المؤقت

## المميزات الجديدة

### 1. لوحة المؤتمر (Conference Board)
- عرض جميع اللاعبين في صف أفقي جميل
- رموز/صور للشخصيات
- حالة حية (حي/ميت/مسكت/عمدة)
- انيميشنات الطفو والتوهج

### 2. تأثير إغلاق العيون
- تأثير واقعي من الأعلى والأسفل
- مدة: 2 ثانية
- السماح للمافيا برؤية بعضهم

### 3. نظام المؤقت المتقدم
- عداد رقمي مركزي
- تغيير الألوان حسب المرحلة
  - 🔵 أزرق للليل
  - 🟡 أصفر للنهار
  - 🔴 أحمر عند الطوارئ (آخر 30 ثانية)

### 4. رموز وز Emojis
- جميع الأدوار لها رموز فريدة
- رموز حالة اللاعب (🤐 مسكت، 🏛️ عمدة، إلخ)

## نصائح للاستخدام

### اختيار الصور:
1. البحث عن صور كرتونية على مواقع مثل:
   - Flaticon
   - OpenDoodles
   - UnDraw

2. تحويل الصور إلى نفس الحجم (240x240px)

3. وضعها في مجلد `public/images/`

### نموذج HTML للصور:
إذا أردت استخدام صور بدلاً من الرموز، يمكن تعديل `client.js`:

```javascript
// بدلاً من:
${p.avatar}

// استخدم:
<img src="/images/${p.avatar}.png" alt="${p.name}">
```
