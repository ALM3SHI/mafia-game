# 🚀 دليل الاستخدام السريع - أداة الخرائط الذكية Pro v2

## ⚡ البدء السريع في 3 خطوات

### خطوة 1️⃣: فتح الأداة
```
1. افتح الملف: smart-map-tool-v2.html
2. سترى الواجهة الرئيسية
3. الأداة جاهزة للاستخدام مباشرة (بدون تثبيت)
```

### خطوة 2️⃣: رفع خريطة
```
📁 رفع الخريطة
    ↓
اختر صورة (PNG, JPG, WebP)
    ↓
ستظهر الخريطة على الشاشة
```

### خطوة 3️⃣: رسم القاعات
```
🔶 رسم قاعة
    ↓
انقر على الخريطة 3 مرات على الأقل
    ↓
اضغط ✅ إنهاء أو Enter
    ↓
تمت إضافة القاعة! 🎉
```

---

## 📖 الأوامر الأساسية

### الرسم المتقدم

#### الالتصاق الذكي 🧲
```
أثناء الرسم:
1. اقترب من زاوية قديمة
2. سترى خط أزرق متقطع
3. سترى دائرة زرقاء على الزاوية
4. انقر → التصق تلقائياً بالزاوية ✅
```

#### الكيبوردات المختصرة
```
Enter     → إنهاء رسم القاعة (إذا كان لديك 3 نقاط فأكثر)
Escape    → ألغي الرسم الحالي
Ctrl+Z    → تراجع عن آخر قاعة
(أو Cmd+Z على Mac)
```

#### عجلة الفأرة
```
Scroll Up   → تكبير الخريطة (+25%)
Scroll Down → تصغير الخريطة (-20%)
```

#### السحب والتحريك
```
اضغط واسحب على الخريطة (بدون الرسم)
→ تحريك الخريطة حول الشاشة
```

## 🎨 إضافة الأبواب

### الطريقة الأولى (من شريط الأدوات)
```
1. انقر على قاعة لتحديدها
2. اضغط 🚪 إضافة باب (في الأعلى)
3. انقر على الخريطة حيث تريد الباب
4. ✅ تم إضافة الباب

كرر الخطوات 2-3 لإضافة أبواب إضافية!
```

### الطريقة الثانية (من لوحة التعديل)
```
1. انقر على القاعة
2. يفتح نافذة التعديل
3. اضغط 🚪 إضافة باب (زر أصفر)
4. انقر على الخريطة
5. ✅ تم الإضافة
```

### حذف باب
```
1. حدّد القاعة
2. في النافذة، جد الباب
3. اضغط ✕ بجانب الباب
4. ✅ تم الحذف
```

## ✏️ تعديل القاعات

### فتح نافذة التعديل
```
انقر على القاعة مرة واحدة
↓
تظهر النافذة على اليسار
```

### تغيير بيانات القاعة

#### 1. المعرف (ID)
```
الحقل: "المعرف (ID)"
مثال: G01, H05, LAB-03
استخدم: للمرجعية بسرعة
```

#### 2. الاسم التوضيحي
```
الحقل: "الاسم التوضيحي"
مثال: "قاعة دراسية G01", "مكتب المدير"
استخدم: للوضوح
```

#### 3. نوع القاعة
```
الخيارات:
📚 قاعة دراسية     (الافتراضي)
💼 مكتب
🏛 إدارة
🪜 درج/مصعد
🚽 دورة مياه
🎭 مدرج
🔬 مختبر
🚪 مدخل
📦 أخرى

فقط انقر على الخيار المطلوب
```

### حفظ التعديلات
```
بعد تعديل أي شيء:

اضغط 💾 حفظ
↓
✅ تم حفظ التغييرات
```

### حذف قاعة
```
في نافذة التعديل:

اضغط 🗑 حذف هذه القاعة
↓
تأكيد الحذف
↓
✅ تم الحذف نهائياً
```

## 🔍 أدوات المشاهدة

#### الأزرار (أسفل اليمين)

## 💾 حفظ وتصدير

### تصدير كـ JSON
```
1. أنهِ رسم جميع القاعات
2. اضغط 🚀 تصدير JSON (أعلى اليمين)
3. سترى الكود JSON
4. اضغط 📋 نسخ الكود
5. ✅ النسخة في الحافظة!
```

### صيغة JSON المُصدَّرة
```json
[
  {
    "id": "G01",
    "label": "قاعة دراسية G01",
    "type": "classroom",
    "color": "#3b82f6",
    "shapeType": "polygon",
    "points": "10.5,20.3 15.2,25.1 18.9,22.4",
    "doors": [
      {
        "id": "door_1",
        "x": 12.5,
        "y": 21.2
      }
    ]
  }
]
```

### استخدام البيانات المصدرة
```
1. انسخ الـ JSON
2. احفظه في ملف: data.json
3. استخدمه في تطبيقك/موقعك
4. معالج: Python, Node.js, إلخ
```

## 🔧 الإعدادات المتقدمة

### تخصيص مسافة الالتصاق
```javascript
في الملف، ابحث عن:
const SNAP_DISTANCE = 15;

غيّرها إلى (بالبكسل):
10  → التصاق أقرب (أدق)
20  → التصاق أبعد (أسهل)
30  → التصاق بعيد جداً
```

### تخصيص حجم الشبكة
```javascript
ابحث عن:
const GRID_SIZE = 20;

غيّرها إلى:
10  → شبكة دقيقة
20  → افتراضي
50  → شبكة كبيرة
```

### إضافة ألوان جديدة
```javascript
ابحث عن:
const PALETTE = [
  '#3b82f6', '#ef4444', ...
];

أضف لون HEX جديد:
'#ff00ff'  → بنفسجي
'#00ff00'  → أخضر فاتح
'#ffff00'  → أصفر
```

## ⚠️ معالجة المشاكل

### المشكلة: الرسومات لا تظهر
```
الحل:
1. تحديث الصفحة (F5 أو Ctrl+R)
2. تأكد أن الخريطة تحملت بنجاح
3. حاول رفع صورة أخرى
```

### المشكلة: لا يمكن رسم القاعة الثانية
```
الحل:
1. تأكد أنك انقرت "إنهاء" للقاعة الأولى
2. الزر 🔶 رسم قاعة يجب أن يكون مرئياً
3. انقر عليه مرة أخرى
```

### المشكلة: الباب لم يُضف
```
الحل:
1. تأكد أنك حددت القاعة (انقر عليها)
2. اضغط 🚪 إضافة باب
3. انقر مرة واحدة على الخريطة
4. تحقق من نافذة التعديل
```

### المشكلة: البيانات لم تُحفظ
```
الحل:
1. تأكد من الضغط على 💾 حفظ
2. الرسالة ✅ تم حفظ البيانات ستظهر
3. تصدير الـ JSON للحفاظ على نسخة
```
